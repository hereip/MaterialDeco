# MaterialDeco

**MaterialDeco** — минималистичные полноэкранные часы для Android с настраиваемым оформлением, анимированными фигурами и визуальными эффектами.

Приложение превращает экран телефона в стильные часы: выбери тему, цвета, формы и шрифт или создай собственный пресет.

## ✨ Возможности

### Часы и экран
- 🕒 Большие цифровые часы в формате `HH:mm`
- 📅 Текущая дата на русском языке
- 🔋 Уровень заряда аккумулятора
- 📱 Полноэкранный режим без системных панелей
- 💡 Экран остаётся включённым во время работы приложения

### Оформление
- 🎨 Несколько визуальных стилей:
  - Material Design 3
  - Material Design 3 Lite
  - Liquid Glass
  - Windows XP
  - Linux TTY
- 🌈 Готовые цветовые палитры и цвета Material You
- 🔷 Фоновые фигуры: случайные формы, круги, квадраты и «печеньки»
- 🔤 Выбор шрифта часов: системный, моноширинный, с засечками и рукописный
- 🎲 Randomize — случайная комбинация оформления

### Настройки и эффекты
- ⚙️ Открытие настроек двойным нажатием по экрану
- 📏 Настройка размера фоновых фигур
- 🌀 Управление анимацией: включение, скорость и количество фигур
- 💾 Пользовательские пресеты — сохраняй и применяй свои комбинации настроек
- 🎧 Music Visualizer — визуализация аудио
- 🌙 Режим заставки с минималистичными часами

> **Примечание о Music Visualizer:** для его работы приложение запрашивает разрешение `RECORD_AUDIO`. Используется Android Audio Visualizer, а не обычная запись с микрофона. Возможность захвата аудио зависит от устройства и версии Android.

## 🛠 Технологии

- **Kotlin** — основной язык разработки
- **Jetpack Compose** — создание интерфейса
- **Material 3** — компоненты и оформление
- **Android SharedPreferences** — сохранение настроек и пресетов
- **Android Audio Visualizer API** — аудиовизуализация
- **Gradle** — система сборки

## 📋 Требования

- Android 12 (API 31) или новее
- JDK 25 для сборки проекта
- Android Studio с поддержкой Kotlin и Jetpack Compose

## 🔨 Сборка

Клонируйте репозиторий:

```bash
git clone https://github.com/HereIP/MaterialDeco.git
cd MaterialDeco
```

Соберите debug-версию:

**Windows:**
```powershell
.\gradlew.bat assembleDebug
```

**Linux / macOS:**
```bash
./gradlew assembleDebug
```

Готовый APK появится в:

```text
app/build/outputs/apk/debug/
```

Откройте проект в Android Studio, чтобы запустить приложение на эмуляторе или подключённом устройстве.
